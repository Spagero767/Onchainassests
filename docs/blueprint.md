# **App Name**: OnChainAssist

## Core Features:

- Smart Contract Interaction: Allows users to interact with deployed smart contracts directly from the app using a web3 provider.
- Transaction Monitoring: Monitors blockchain transactions related to the user's wallet, providing real-time updates on pending and confirmed transactions.
- On-chain Task Automation: Generate code to automate common on-chain tasks, such as setting up recurring payments, or automating responses to certain contract events.
- Multi-Chain Support: Support for multiple EVM-compatible blockchains (e.g., Ethereum, Polygon, BSC) for broader accessibility.
- Gas Fee Estimation: Estimate gas fees for transactions, allowing users to optimize costs.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to reflect trust and technology.
- Background color: Light gray (#F5F5F5), providing a clean and modern look.
- Accent color: Electric purple (#8E44AD) for highlights and interactive elements.
- Body and headline font: 'Inter' for a clean, modern sans-serif.
- Use minimalist, geometric icons related to blockchain concepts and actions.
- Use a clean, card-based layout to organize blockchain data. The cards provide transaction details and key data points in an easy-to-digest way.
- Subtle animations when loading data and confirming transactions to enhance user experience.
